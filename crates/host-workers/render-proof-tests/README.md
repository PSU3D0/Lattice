# host-workers/render-proof-tests

Render→run proof (packet W2, ops/phase1-clone-engine-plan-2026-06-12.md): the
gate that says the wrangler.toml produced by `flows deploy render` is real.

- `src/lib.rs` — a worker that serves ONLY the `s1_echo` example flow through
  the existing host-workers entry machinery (`host_workers::handle_fetch` +
  `get_bundle()`, same shape as `../workerd-tests` and the s7 fixture). Its
  runtime needs are exactly what the renderer emits for s1_echo: one `FLOW_DO`
  Durable Object.
- `src/index.test.ts` — parses the RENDERED wrangler.toml with wrangler's own
  config parser and derives the entire miniflare setup from it (entry script,
  compatibility date, DO bindings + sqlite migrations, kv/r2/vars), then
  invokes `POST /echo` and asserts the flow executed.

`wrangler.toml` here is generated by `npm run render` and gitignored — it is
never hand-written; that is the point.

## Run

```bash
npm install   # once
npm test      # = flows deploy render + ensure-worker-build guard + vitest
```

`worker-build >= 0.7` must be on PATH (one-time `cargo install
worker-build@^0.7`, or set `LATTICE_AUTO_INSTALL_WORKER_BUILD=1` — see
`scripts/ensure-worker-build.sh`).
